# Моя история

Кроссплатформенный личный дневник воспоминаний для iPhone, Android и ПК.

## Первая версия
- Лента событий
- Добавление события
- Дата и время
- Место
- Текстовая заметка
- Фото/видео/голосовые
- PWA
- Supabase для структуры данных
- Google Drive для медиафайлов

## Логика хранения
Каждый медиафайл получает внутренний ID приложения. Записи дневника ссылаются на этот ID, а не на прямой URL Google Drive. Это позволяет переносить медиа между Google-аккаунтами без разрыва связей в дневнике.
